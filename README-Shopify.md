# Shopify Dropshipping Theme

A modern, responsive Shopify theme designed for dropshipping stores selling smart home devices and electronics.

## 📋 Theme Overview

This theme is built for Shopify Online Store 2.0 and provides a complete e-commerce solution with:

- **Responsive Design**: Mobile-first approach with Tailwind CSS
- **Conversion Optimized**: Sticky header, quick add-to-cart, trust badges
- **Dynamic Sections**: Customizable homepage with drag-and-drop sections
- **Professional Styling**: Clean, modern design with soft shadows and rounded corners

## 🏗️ Theme Structure

### Layout
- `theme.liquid` - Main layout file with HTML structure

### Templates
- `index.json` - Homepage template
- `product.json` - Product page template
- `collection.json` - Collection page template
- `cart.json` - Cart page template
- `page.json` - General page template

### Sections
- `header.liquid` - Navigation header with cart
- `footer.liquid` - Site footer with links
- `hero-banner.liquid` - Hero section with CTA
- `product-grid.liquid` - Product listing grid
- `featured-products.liquid` - Featured products showcase
- `categories.liquid` - Category navigation
- `testimonials.liquid` - Customer testimonials
- `promotional-banner.liquid` - Promotional offers

### Snippets
- `product-card.liquid` - Reusable product card component
- `price.liquid` - Price display component
- `rating.liquid` - Star rating display
- `cart-drawer.liquid` - Slide-out cart drawer

### Assets
- `base.css` - Main stylesheet with Tailwind CSS
- `theme.js` - JavaScript for cart and interactions

## 🚀 Installation

1. Download the theme files
2. Zip the entire theme folder
3. In Shopify admin, go to Online Store > Themes
4. Click "Upload" and select the zip file
5. Click "Publish" to activate the theme

## ⚙️ Configuration

### Homepage Setup
1. Go to Online Store > Themes > Customize
2. Add sections to the homepage:
   - Header
   - Hero Banner
   - Categories
   - Featured Products
   - Product Grid
   - Testimonials
   - Footer

### Section Settings
Each section has customizable settings:
- **Hero Banner**: Title, subtitle, button text and links
- **Categories**: Category titles, descriptions, and links
- **Testimonials**: Customer names, reviews, and ratings
- **Promotional Banner**: Offer text and links

## 🎨 Customization

### Colors
The theme uses a blue color scheme that can be customized via CSS variables in `base.css`.

### Typography
Uses Inter font family for clean, modern typography.
